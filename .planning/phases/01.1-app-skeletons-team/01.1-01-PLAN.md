<objective>
Extend the lead-owned pin guard so `pnpm-workspace.yaml` can carry pnpm 12's build-approval map `allowBuilds` (D-06), with strict per-entry validation and tests, and prove against the real pnpm 12.15.0 that this is the key it reads. This unblocks UL-7 (prisma, @prisma/engines, @swc/core) and UL-6/UL-12 (esbuild and any other install-script dependency).

Purpose: pnpm 12 defaults to `strictDepBuilds: true`, so any dependency with an install script that is not listed fails the install with `ERR_PNPM_IGNORED_BUILDS`. The guard today rejects every unknown top-level key, so the key must be allow-listed first, in a reviewed change (D-06, Phase 1 D-07).
Output: `scripts/check-pins.mjs` and its tests, and the README "Dependency rules" text.

Planner evidence (probe run 2026-11-12 in a scratch dir with pnpm 12.15.0): no entry → `ERR_PNPM_IGNORED_BUILDS`, exit 1; `allowBuilds: { esbuild: false }` → install passes silently; `esbuild: true` → `postinstall$ node install.js` runs; `onlyBuiltDependencies: [esbuild]` → still `ERR_PNPM_IGNORED_BUILDS` (ignored since pnpm 11). The executor re-proves it in Task 1.
</objective>
