| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01.1-07 | Elevation of Privilege | bot approval counting toward the required review | medium | mitigate | `request_changes_workflow: false` (and `auto_approvals.enabled: false` when the schema has it); the `main` ruleset still requires one human approval |
| T-01.1-08 | Information Disclosure | third-party app reading the code | low | accept | The repository is public; the app gets read access to code that is already public. `.planning/**` is excluded from review, not hidden |
| T-01.1-09 | Tampering | `.coderabbit.yaml` edited to skip paths | low | mitigate | CODEOWNERS makes the file lead-owned, so the change needs the lead's review |
| T-01.1-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs in this plan |
