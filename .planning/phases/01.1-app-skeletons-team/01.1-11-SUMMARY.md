## Deviations from Plan

### Auto-fixed Issues

**1. [Orchestrator rule] Replay clone under the session scratchpad, teardown split into separate calls**
- **Issue:**
  - The verify uses `mktemp -d` (system temp) and does `pkill`, `down -v` and `rm -rf "$D"` in one line.
  - The orchestrator asked for the clone under the session scratchpad, and earlier waves showed that the harness may refuse one-liners that mix `rm` with other commands.
- **Fix:** the same steps and assertions ran as separate calls:
  - README grep;
  - clone + quick start + poll;
  - `pkill` + `down -v` for `app-replay`, checking that no container or volume remained;
  - `rm -rf` of the literal scratchpad path.
- **Commit:** n/a (verification only)

**2. [Scope boundary] Repo-wide actionlint still fails on the pre-existing SC2034**
- **Issue:** Task 3's verify runs actionlint on every workflow. The only finding is the deferred `main-push-guard.yml:36` SC2034 (01.1-08), in a lead-owned file this plan does not touch.
- **Action:** `actionlint .github/workflows/ci.yml .github/workflows/release.yml` exits 0, and the rest of the verify ran unchanged and passed (`check:all` 17/17 Turbo tasks, Storybook build).

**3. [Tooling] Secret-read hook blocked one Bash call**
- **Issue:** The heredoc that wrote `apps/api/README.md` contained the literal path of a package-level env file, so the PreToolUse secret guard refused the whole command. Nothing was read or written.
- **Fix:** I wrote both app READMEs with the Write tool and phrased the sentence as "a `.env` in this package, if you add one". No env file was opened at any point.
