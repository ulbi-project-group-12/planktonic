## Phase Goal

ROADMAP Goal: see 01-01-PLAN.md (verbatim quote and MVP note). This plan adds the api link of the pipeline skeleton: a package that passes all four tasks and an image the release workflow can build.

<objective>
Create the `apps/api` placeholder (D-02) and its placeholder Docker image (D-17). The package has trivial but real `lint`, `typecheck`, `test` and `build` scripts, and a tiny `src/main.ts` that prints the package name, `APP_VERSION` and `PRODUCT_NAME`. The image builds from the repo root on the digest-pinned `node:26.13.0-alpine3.24`, runs as the non-root `node` user, and gets only an allow-listed build context. The product name enters only as a build-arg; no file here spells it (D-33, D-34, D-35).

Purpose: SC1 (pipeline across apps) and SC5 (release.yml has a real Dockerfile to build). No NestJS code: that skeleton is Phase 1.1 ticket 1.5, the team's learning work.
Output: `apps/api/` (package.json, src/main.ts, tsconfig.json, tsconfig.build.json, eslint.config.js, README.md, Dockerfile) and the root `.dockerignore`.
</objective>
