## Phase Goal

ROADMAP Goal (verbatim): "Anyone clones the repo and `pnpm install --frozen-lockfile && pnpm turbo run lint typecheck test build` passes. Every PR and push to `main` runs the same checks in CI, `main` accepts changes only through a PR with green checks, and publishing a GitHub Release builds the images and pushes them to GHCR."

MVP note: the ROADMAP Goal line is not in "As a / I want to / so that" form, so no user story is invented here. Run `/gsd-mvp-phase 1` if a story framing is wanted. The walking skeleton for this phase is the pipeline itself, see `01-SKELETON.md`.
